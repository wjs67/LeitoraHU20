REQUISITOS SISTEMA
══════════════════════════════════════════════════════════════════

Antes de executar, verifique se você possui:

✓ Windows 10 ou Windows 11 (x64)
✓ .NET 6.0 Runtime ou superior
✓ Leitor Biométrico Secugen HU20 conectado à USB
✓ Driver do HU20 instalado


PASSO 1: INSTALAR .NET 6.0 RUNTIME
══════════════════════════════════════════════════════════════════

Se você ainda NÃO tem .NET 6.0 Runtime instalado:

1. Visite: https://dotnet.microsoft.com/download/dotnet/6.0
2. Procure por ".NET 6.0 Runtime" (não o SDK)
3. Baixe a versão Windows x64
4. Execute o instalador (.exe) e siga as instruções
5. Reinicie o computador se solicitado

Para verificar se está instalado:
- Abra PowerShell ou Prompt de Comando
- Digite: dotnet --version
- Deve mostrar versão 6.0.x ou superior


PASSO 2: EXTRAIR O ARQUIVO ZIP
══════════════════════════════════════════════════════════════════

1. Localize o arquivo: LeitoraHU20-v1.0.0.zip
2. Clique com botão direito → "Extrair tudo..."
3. Escolha a pasta de destino (exemplo: C:\Programas\LeitoraHU20)
4. Aguarde a extração ser concluída

CONTEÚDO DO ZIP:
- LeitoraHU20.exe          → Programa principal
- *.dll                    → Bibliotecas necessárias (NÃO REMOVA)
- README.md                → Documentação técnica
- LICENSE                  → Termos de licença


PASSO 3: PREPARAR O LEITOR HU20
══════════════════════════════════════════════════════════════════

Antes de executar o programa:

1. CONECTAR O LEITOR
   ✓ Conecte o Secugen HU20 a uma porta USB
   ✓ Aguarde 5 segundos para ser reconhecido
   ✓ Verifique se o LED do leitor está aceso

2. VERIFICAR DRIVER
   ✓ Abra "Gerenciador de Dispositivos"
   ✓ Procure por "Secugen" ou "HU20"
   ✓ Não deve haver ⚠ (triângulo amarelo) de erro
   
   Se houver erro:
   - Reinstale o driver do SDK Secugen
   - Contato Secugen: https://www.secugen.com/


PASSO 4: EXECUTAR O PROGRAMA
══════════════════════════════════════════════════════════════════

OPÇÃO A - Clique Duplo (Mais Fácil):
1. Localize o arquivo LeitoraHU20.exe (dentro da pasta extraída)
2. Clique duas vezes para executar
3. O programa abrirá uma janela de terminal

OPÇÃO B - Linha de Comando (Mais Controle):
1. Abra PowerShell
2. Digite: cd "C:\caminho\para\LeitoraHU20"
3. Digite: .\LeitoraHU20.exe
4. Pressione Enter


SAÍDA ESPERADA
══════════════════════════════════════════════════════════════════

Se tudo estiver correto, você verá:

    H54200804821

Este é o número serial do seu leitor HU20.


MENSAGENS DE ERRO E SOLUÇÕES
══════════════════════════════════════════════════════════════════

❌ "Dispositivo HU20 não encontrado"
   → Verifique se o leitor está conectado à USB
   → Verifique se o LED está aceso
   → Tente outra porta USB
   → Reinicie o computador

❌ "'dotnet' is not recognized as an internal or external command"
   → .NET 6.0 Runtime NÃO está instalado
   → Siga o PASSO 1 acima
   → Reinicie após instalar

❌ "Falha ao inicializar o SDK SecuGen"
   → O SDK SecuGen pode não estar instalado corretamente
   → Reinstale o SecuGen FDx SDK Pro
   → Verifique o caminho do driver: C:\Program Files\SecuGen\

❌ Programa abre e fecha rapidamente
   → Normalmente significa sucesso!
   → Para ver a saída: execute via PowerShell (OPÇÃO B)

⚠️  "ERR: Can't open the key"
   → Avisos normais do SDK - NÃO SÃO ERRO
   → O programa funcionará normalmente
